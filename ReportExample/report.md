# Report Example

## Displaying an Image in Markdown

Below is an example of embedding a local image using Markdown syntax:

![Example Image](imgs/example.png)

You can also add a reference-style link for reuse:

![Example Image Again][example]

[example]: imgs/example.png

## Resizing with HTML

Markdown doesn't support image resizing natively, but you can use HTML:

<img src="imgs/example.png" alt="Example Image" width="400"/>
